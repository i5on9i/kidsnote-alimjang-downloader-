## 실행 전 준비물

- Windows 10 이상
- Python 3.10 이상
- 인터넷 연결 (첫 실행 때 패키지 + Chromium을 내려받습니다)
- 키즈노트 계정 (학부모 / 교사 등 본인 계정)

> Python이 이미 있는지 모르겠다면, `Win + R` → `cmd` 입력 → 아래를 쳐보세요. 버전이 뜨면 있는 겁니다.
>
> ```bat
> python --version
> ```

## 빠른 시작 (처음이라면 여기만 보세요)

```text
1. 이 저장소를 다운로드합니다 (Code → Download ZIP → 압축 풀기)
2. Python을 설치합니다 (없으면 아래 참고, 설치할 때 "Add python.exe to PATH" 꼭 체크)
3. 폴더 안에서 run.bat을 더블클릭합니다
4. 앱이 뜨면 [브라우저로 로그인] → 키즈노트에 평소대로 로그인 → 브라우저 창을 닫습니다
5. [아이 새로고침] → 아이 선택 → 알림장 고르기 → [▶ 선택한 알림장 이미지 일괄 다운로드]
```

처음 한 번만 가상환경 + 패키지 + Chromium 설치라서 몇 분 걸릴 수 있습니다. 그다음부터는 바로 앱이 뜹니다.

### Python 설치 방법 (처음 설치하는 분)

1. https://www.python.org/downloads/ 에 들어갑니다.
2. `Download Python 3.x.x` 버튼을 눌러 설치 파일을 받습니다.
3. 설치 파일을 실행하고, **맨 아래 `Add python.exe to PATH`를 꼭 체크**합니다. 이걸 빼먹으면 `python을 찾을 수 없습니다` 오류가 납니다.
4. `Install Now`를 눌러 설치하고, PC를 한 번 재시작합니다.

### 다운로드 방법

**방법 A. ZIP으로 받기 (Git 사용을 안 하는 분)**

1. 이 페이지 위쪽 초록색 `Code` 버튼 → `Download ZIP` 클릭
2. 받은 ZIP을 원하는 곳에 압축 풀기 (예: `C:\kidsnote-downloader`)
3. 그 폴더 안에서 `run.bat` 더블클릭

**방법 B. Git으로 받기**

```bat
git clone https://github.com/<본인-계정>/kidsnote-alimjang-downloader.git
cd kidsnote-alimjang-downloader
run.bat
```

> `<>` 안은 본인 GitHub 계정 / 저장소 이름으로 바꿔주세요. 위 주소는 예시입니다.

## 사용 순서 (자세히)

### 1. 로그인

1. 앱 위쪽 `1. 로그인`에서 **[브라우저로 로그인]** 을 누릅니다.
2. 크롬 창이 뜹니다. 키즈노트에 **평소대로 직접 로그인**하세요. 앱이 아이디 / 비밀번호를 입력하거나 저장하지 않습니다.
3. 로그인 후, 아이별 앨범 / 알림장 화면을 한 번씩 열어두면 아이 정보가 잘 저장됩니다.
4. 다 됐으면 **브라우저 창을 닫으세요.** 닫으면 세션(쿠키)만 이 PC에 저장됩니다.
5. 앱에 `● 로그인됨 (세션 있음)`이라고 뜨면 성공입니다.

> 로그인 창이 닫히지 않거나, 로그인했는데도 `로그인 안 됨`으로 뜨면 [문제 해결](#문제-해결-troubleshooting)의 `세션이 만료된 것 같습니다` 항목을 보세요.

### 2. 아이 선택

- **[아이 새로고침]** 을 누르면 아이 목록이 뜹니다.
- 아이가 안 떠도 URL 입력으로는 다운로드가 됩니다. 아이 선택은 폴더 이름(아이 이름 폴더)에만 영향을 줍니다.

### 3. 알림장 고르기 — 둘 중 하나

**A) [알림장 목록에서 선택] 탭 (보통은 이걸 쓰세요)**

1. **[알림장 목록 불러오기]** 를 누릅니다.
2. 목록에서 원하는 글 제목을 클릭해서 ☑ 체크합니다. 다시 클릭하면 해제됩니다.
3. 검색어 입력하면 제목으로 필터됩니다.
4. `[전체 선택]` / `[전체 해제]`로 한 번에 고를 수도 있습니다.

**B) [URL 직접 입력] 탭 (목록이 안 잡힐 때 가장 확실한 방법)**

1. 키즈노트 웹에서 원하는 알림장을 엽니다.
2. 주소창 URL을 복사해서 한 줄에 하나씩 붙여넣습니다.
3. 예:
   ```
   https://www.kidsnote.com/...
   https://www.kidsnote.com/...
   ```

### 4. 다운로드 설정

| 설정 | 기본값 | 설명 |
|---|---|---|
| 저장 폴더 | `내 사진\kidsnote-alimjang` | `[찾아보기…]`로 바꿀 수 있습니다 |
| `날짜_제목 폴더로 정리` | 켜짐 | `아이\2026-05-12_오늘은 소풍 갔어요\`처럼 정리합니다. 끄면 저장 폴더에 바로 저장됩니다 |
| `동영상도 함께 받기` | 꺼짐 | 필요할 때만 켜세요 |
| `이미 받은 파일 건너뛰기` | 켜짐 | 이미 있는 파일은 다시 안 받습니다. 다시 받고 싶으면 끄거나, 파일을 지우고 다시 받으세요 |
| `사진 이름 자동 변경` | 켜짐 | 아래 [사진 이름 자동 변경](#사진-이름-자동-변경) 참고 |

### 5. 다운로드

**[▶ 선택한 알림장 이미지 일괄 다운로드]** 를 누릅니다.

아래 `로그`에 진행 상황이 뜹니다.

```
[1/3] 2026-05-12_오늘은 소풍 갔어요 - 이미지 수집 중…
  → 이미지 12장 찾음. 다운로드 시작…
  → 완료: 새로 12장, 건너뜀 0장, 실패 0장
  → 사진 이름 자동 변경 완료 - 총 12장 변경됨
전체 완료 - 새로 12장, 건너뜀 0장, 실패 0장, 이름 변경 12장
```

끝나면 팝업으로 `다운로드 완료!`가 뜹니다.

## 저장되는 모습

```
Pictures\kidsnote-alimjang\
  └─ 김민준\
      ├─ 2026-05-12_오늘은 소풍 갔어요\
      │   ├─ 20261106_095100.jpg
      │   ├─ 20261106_095200.jpg
      │   └─ 20261106_095300.jpg
      └─ 2026-05-13_비 오는 날 실내놀이\
          └─ 20261106_101500.jpg
```

- 폴더 이름은 `날짜_제목`입니다. 제목에 Windows에서 못 쓰는 문자(`\ / : * ? " < > |`)가 있으면 `_`로 바뀝니다.
- `날짜_제목 폴더로 정리`를 끄면 아이 폴더 / 저장 폴더에 바로 저장됩니다.

## 사진 이름 자동 변경

다운로드가 끝나면 각 알림장 폴더마다 사진 이름을 바꿉니다.

- UI에서 `다운로드한 사진 이름 자동으로 변경한다` 체크박스로 켜고 끌 수 있습니다. 기본값은 **켜짐**입니다.
- 끄면 원래 파일명(`001_...jpg` 같은 형태) 그대로 둡니다.

### 바꾸는 규칙

우선순위는 이렇습니다.

1. **`EXIF` 촬영일**이 있으면 그걸로 바꿉니다.
2. `EXIF`이 없으면 **키즈노트 API 날짜**(알림장에 붙은 사진의 업로드 / 촬영 날짜)를 씁니다.
3. 둘 다 없으면 **건너뜁니다.**


### 이름 형식

- 형식: `YYYYMMDD_HHMMSS.jpg` (예: `20261106_095100.jpg`)
- 같은 시간이면 `_1`, `_2`를 붙입니다. (예: `20261106_095100_1.jpg`)
- 대상은 `.jpg / .jpeg / .png / .heic / .heif / .webp / .tiff`만이고, `.gif` / 동영상은 바꾸지 않습니다.

### 수동으로 이름만 바꾸고 싶을 때

앱 없이 이름만 바꾸고 싶으면 `rename_photos.py`를 쓰세요.

```bat
:: 미리보기만 (바꾸지 않음)
python rename_photos.py "F:\kidsnote3"

:: 실제로 바꾸기 (로컬 사진용: EXIF 없으면 파일시간으로 바꿈)
python rename_photos.py "F:\kidsnote3" --real

:: 키즈노트 다운로드 폴더용: EXIF 없으면 파일시간으로 바꾸지 않고 건너뜀
python rename_photos.py "F:\kidsnote3" --real --no-mtime
```

> 로컬에서 찍은 사진은 파일시간이 촬영 시간과 비슷해서 `--real`만으로 충분합니다.
> 키즈노트에서 받은 파일은 파일시간이 다운로드 시간이라서 `--no-mtime`을 쓰세요.

## CLI로 쓰고 싶을 때

GUI 없이 명령줄로도 쓸 수 있습니다.

```bat
.venv\Scripts\activate

:: 알림장 목록만 보기
python app.py --cli --list

:: 검색어로 목록 보기
python app.py --cli --list --keyword "소풍"

:: URL로 바로 다운로드
python app.py --cli --urls "https://www.kidsnote.com/..." "https://www.kidsnote.com/..."

:: 저장 폴더 지정 + 동영상도 함께
python app.py --cli --urls "https://www.kidsnote.com/..." --output "C:\Users\내이름\Pictures\kidsnote-alimjang" --video
```

> `--cli` 없이 `python app.py`를 실행하면 GUI가 뜹니다.

## exe로 만들기 (선택)

Python이 없는 PC에서도 쓰고 싶으면 exe로 만들 수 있습니다.

1. `run.bat`을 한 번 실행해서 `.venv`를 만듭니다.
2. `build_exe.bat`을 더블클릭합니다.
3. `dist\KidsnoteAlimjangDownloader.exe`가 만들어집니다.
4. 이 exe를 다른 PC로 옮겨서 실행해도 됩니다. 단, 첫 실행 때 Chromium이 필요할 수 있습니다.

> exe를 만들어도 로그인은 똑같이 브라우저에서 직접 해야 합니다. 비밀번호가 exe 안에 저장되지 않습니다.

## 자주 묻는 질문 (FAQ)

**Q. 내 아이디 / 비밀번호가 어딘가에 저장되나요?**
A. 저장되지 않습니다. 브라우저에서 직접 로그인하고, 브라우저를 닫으면 세션(쿠키)만 이 PC에 저장됩니다. 자세한 건 [개인정보 / 보안](#개인정보--보안)을 보세요.

**Q. 알림장이 아닌 앨범도 받을 수 있나요?**
A. 목록에 앨범 링크가 같이 뜨면 받을 수 있습니다. 다만 이 앱의 주 대상은 알림장입니다. 원본 `bestend/kidsnote`는 앨범 전용 CLI이니, 앨범만 대량으로 받고 싶으면 원본도 참고하세요.

**Q. 아이가 2명 이상이면 어떻게 되나요?**
A. 아이를 선택하면 그 아이 폴더 아래로 저장됩니다. 다른 아이 것은 아이를 바꿔서 다시 받으세요.

**Q. 사진이 아닌 동영상도 받나요?**
A. `동영상도 함께 받기`를 켜면 받습니다. 기본값은 꺼짐입니다.

**Q. 중간에 멈추면 처음부터 다시 받아야 하나요?**
A. 아닙니다. `이미 받은 파일 건너뛰기`가 켜져 있으면 이미 받은 파일은 건너뛰고, 안 받은 것만 받습니다.

**Q. 맥 / 리눅스에서도 되나요?**
A. 이 저장소는 Windows를 기준으로 만들었습니다. Python 코드 자체는 맥 / 리눅스에서도 돌아갈 수 있지만, `run.bat` 대신 수동으로 가상환경 + `pip install -r requirements.txt` + `python app.py`를 실행해야 합니다. Windows 외 환경은 공식 지원 대상이 아닙니다.

## 문제 해결 (Troubleshooting)

| 증상 | 해결 방법 |
|---|---|
| `python을 찾을 수 없습니다` | Python 재설치할 때 `Add python.exe to PATH` 체크했는지 확인하고, PC 재시작 |
| `Playwright가 설치되지 않았습니다` | `run.bat`을 다시 실행하거나 `python -m playwright install chromium` 실행 |
| `세션이 만료된 것 같습니다` | `[브라우저로 로그인]`을 다시 실행. 브라우저에서 로그인한 뒤 창을 닫아야 세션이 저장됨 |
| 로그인했는데 목록이 비어 있음 | 키즈노트 웹 구조가 바뀌었을 수 있음. **[URL 직접 입력] 탭**으로 URL 붙여넣기. 그래도 안 되면 `python debug_list.py` 결과를 이슈에 붙여주세요 |
| 특정 알림장에 이미지가 0장 | 이미지가 없는 글이거나, 스크롤이 끝나기 전에 닫힌 경우. 다시 한 번 다운로드 시도 |
| 아이가 안 보임 | 로그인할 때 아이별 앨범 화면까지 한 번씩 들어가야 함 (원본 kd와 동일) |
| `PermissionError` / 파일이 잠김 | 해당 폴더의 사진을 다른 프로그램(사진 앱, 탐색기 미리보기 등)에서 열고 있지 않은지 확인하고 닫은 뒤 다시 실행 |

- **비밀번호를 앱이 저장하지 않습니다.** 브라우저에서 직접 로그인하고, 브라우저를 닫으면 세션(쿠키)만 로컬에 저장됩니다.

- 이 앱은 본인 계정으로 본인이 볼 수 있는 알림장만 다운로드하는 용도입니다. 타인의 계정 / 게시물에는 사용하지 마세요.
- 세션 파일은 다른 사람에게 주면 그 사람이 내 계정으로 들어갈 수 있는 열쇠와 같습니다. 공유하거나 GitHub에 올리지 마세요. `.gitignore`에 이미 들어 있습니다.
- 다운로드한 사진도 개인정보가 될 수 있습니다. 공유 폴더 / 클라우드에 올릴 때는 주의하세요.
